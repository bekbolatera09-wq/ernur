# Монополия тарих

Қазақстан тарихына арналған, бір ойын бөлмесінде 2–12 адам онлайн ойнайтын веб-ойын. Ойын тақтасы мен барлық ережелердің беделді күйі Node.js серверінде сақталады; клиенттер Socket.IO арқылы бірдей сұрақ, таймер, кезек, ұпай және фишка қозғалысын көреді.

Жарияланған сайт: <https://historical-board-game.onrender.com/>. Сайтты іздеу жүйелерінен «Монополия тарих» деп іздеп табу үшін Google сияқты жүйелер сайтты өз индексіне енгізуі керек. Жаңа сайттың индекске енуі бірнеше күннен бірнеше аптаға дейін созылуы мүмкін, ал іздеу нәтижесінде шығуына кепілдік жоқ.

## Файлдар

- `server.js` — Express, Socket.IO, бөлмелер, ойын ережелері, сұрақ таймері және серверлік тексерулер.
- `package.json` — іске қосу пәрмені мен Node.js / сервер тәуелділіктері.
- `public/index.html` — ойын беті мен бөлме, сұрақ және марапат терезелері.
- `public/styles.css` — қолданыстағы дизайн, responsive көрініс, шахмат королі фишкалары және кубик анимациясы.
- `public/game.js` — Socket.IO клиенті, бөлмеге қосылу, экран мен сервер күйін көрсету.
- `public/history-board.png` — тарихи ойын картасы.
- `.gitignore` — тәуелділік пен жергілікті құпия файлдарды Git-тен шығарады.
- `render.yaml` — Render Web Service параметрлері.

## Жергілікті іске қосу

Node.js 18 немесе одан жаңасын орнатып, жоба бумасында терминал ашыңыз:

```powershell
npm install
npm start
```

Браузерде <http://localhost:3000> мекенжайын ашыңыз. Онлайн ойынды тексеру үшін екі бөлек браузер қойындысын ашып, біріншісінде бөлме құрып, екіншісінде оның коды арқылы қосылыңыз. Екі қойынды да осы серверге қосылған болуы керек; `index.html` файлын тікелей ашу онлайн Socket.IO серверін іске қоспайды.

Ойын жасаушы бөлме құру кезінде ойыншылардың шекті санын 2–12 аралығында таңдайды. Бөлме коды мен бөлісу сілтемесін достарына жібере алады. Қосылған ойыншылар хост «Ойынды бастау» түймесін басқанша лоббиде көрінеді. Ойын басталған соң, қайта қосылған ойыншы өз ойыншысы мен бөлме күйін қалпына келтіреді.

## GitHub-қа жариялау

GitHub-та жаңа, бос репозиторий жасағаннан кейін жоба бумасында мына пәрмендерді орындаңыз:

```powershell
git init
git add .
git commit -m "Build online historical board game"
git branch -M main
git remote add origin https://github.com/<username>/<repository>.git
git push -u origin main
```

`<username>` және `<repository>` мәндерін өз аккаунтыңыз бен репозиторий атауына ауыстырыңыз.

## Render.com-ға орналастыру

1. [Render.com](https://render.com/) сайтына кіріп, GitHub аккаунтын байланыстырыңыз.
2. **New → Web Service** таңдаңыз да, осы репозиторийді көрсетіңіз.
3. Runtime: **Node**, Build Command: `npm install`, Start Command: `npm start` деп қойыңыз.
4. Free планын таңдаңыз да, **Create Web Service** басыңыз. Репозиторийдегі `render.yaml` осы мәндерді алдын ала береді.
5. Deploy аяқталған соң Render берген `https://...onrender.com` сілтемесін ашып, оны достарыңызбен бөлісіңіз.

Render Free жоспарында сервер 15 минут белсенділік болмағанда ұйықтауы мүмкін; келесі кіргенде алғашқы ашылуы шамамен 30–50 секунд алады. Ойын бөлмелері сервер жадында сақталады және соңғы әрекеттен кейін екі сағат өткенде автоматты түрде жабылады.

## Google-дан іздеп табу

1. <https://search.google.com/search-console> сайтына кіріп, Google аккаунтыңызбен кіріңіз.
2. **URL prefix** ретінде `https://historical-board-game.onrender.com/` қосыңыз.
3. Search Console осы сайтқа арналған HTML meta-тегін береді. Тегін `public/index.html` файлының `<head>` бөлігіне қойып, GitHub-қа жариялағаннан кейін Render жаңартылғанша күтіңіз.
4. Search Console ішінде **Verify** басыңыз.
5. **Sitemaps** бөліміне `https://historical-board-game.onrender.com/sitemap.xml` жіберіңіз.
6. URL Inspection құралында сайттың негізгі сілтемесін тексеріп, **Request indexing** басыңыз.
7. Google сайтты қарап, нәтижесіне қосуды өзі шешеді; бұл бірден болмауы мүмкін және нақты іздеу сөзінде шығуына кепілдік жоқ.

## Онлайн және сервер қауіпсіздігі

Ойын коды 4–6 саннан тұрады. Бөлмеде 12-ден артық ойыншы, қайталанатын ат немесе бір түсті екі фишка қабылданбайды. Сервер есімді, бөлме кодын, фишка түсін, ағымдағы кезекті, жауап нұсқасын және сұрақ уақытын тексереді; кубик саны сервер жағында кездейсоқ анықталады. Қайта қосылу үшін ойыншы идентификаторы браузердің `localStorage` жадында, бөлме коды ағымдағы қойынды сессиясында сақталады.
